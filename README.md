# LimeStore Cloud Client

Окно-клиент для сайта: пользователь запускает приложение — открывается `https://lime-store.top` в своём окне без адресной строки. Сайт сам редиректит на домен магазина (`ehmed.lime-store.top`).

Внутри — Chromium (Electron), поэтому сайт ведёт себя как в браузере: вход запоминается, печать открывается системным диалогом, сканер штрихкодов работает как клавиатура. Обновлять клиент не нужно — он всегда грузит сайт с сервера.

## Требования

- Node.js 20+
- pnpm

## Сборка установщика (Windows)

```
pnpm install
pnpm dist
```

Готовый файл: `dist/LimeStore-Setup-1.0.0.exe`.
Установка per-user, без прав администратора; ярлыки на рабочем столе и в меню Пуск.

Без сертификата подписи кода Windows покажет «Неизвестный издатель» (SmartScreen) — это ожидаемо.

## Сборка для Linux

```
pnpm install
pnpm dist:linux
```

Готовый файл: `dist/LimeStore-1.0.0.AppImage`. Установка не нужна: двойной клик, без root.

- Обычный запуск AppImage требует FUSE 2 (`sudo dnf install fuse-libs` на Fedora, `libfuse2t64` на Ubuntu).
- Без FUSE: `./LimeStore-1.0.0.AppImage --appimage-extract-and-run`.
- `deb`/`rpm` в конфиге не включены: сборщик использует свой fpm, которому на Fedora нужен `libcrypt.so.1` (`sudo dnf install libxcrypt-compat`). Нужны пакеты — добавь `- deb`/`- rpm` в `linux.target` и поставь библиотеку.

## Запуск без сборки

```
pnpm start
pnpm start -- --url=http://localhost:3000     # тестовый сервер
```

## Тесты

```
pnpm test
```

Покрыта только логика адресов (`src/url.js`): какой хост считается своим, какой уходит во внешний браузер.

## Где что менять

| Что | Где |
|---|---|
| Прод-адрес сайта | `DEFAULT_URL` в `src/url.js` |
| Название, версия | `productName` в `electron-builder.yml`, `version` в `package.json` |
| Иконка | `build/icon.ico` (Windows), `build/icon.png` (окно) |
| Пункты меню | `buildMenu()` в `src/main.js` |

## Поведение

- Вход сохраняется между запусками (профиль в `%APPDATA%\LimeStore`).
- Ссылки на чужие домены открываются в системном браузере, не внутри окна.
- `window.open('', '_blank')` (так сайт печатает чеки и документы) открывает настоящее окно — печать работает как в браузере.
- Второй запуск приложения просто поднимает уже открытое окно.
- При удалении приложения данные входа не стираются (`deleteAppDataOnUninstall: false`).

## Что проверить на реальной кассе

1. Печать чека: `Ctrl+P` и кнопка печати в интерфейсе открывают системный диалог принтера.
2. Сканер штрихкодов вводит код в поле поиска.
3. После перезапуска клиента вход сохраняется.
